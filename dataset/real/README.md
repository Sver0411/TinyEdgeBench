# Real sensor traces

No real trace has been collected or labeled for this version. Do not place generated samples here or report real-world accuracy from an unlabeled trace.

When sensors are connected, keep the raw timestamped channels that actually exist (for example `timestamp,temp,hum,light`), note sensor model and units, and record the experimental conditions. Missing channels remain missing; they must not be fabricated to match the synthetic data. Compute the existing eight features only when the required three channels are available, and compare feature distributions before interpreting predictions. Ground-truth class labels require a separately documented, controlled experiment.
